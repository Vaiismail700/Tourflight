# Tourflight আপডেট

বিদ্যমান GitHub রিপোজিটরিতে ZIP খুলে নিচের ফাইলগুলো আগের একই জায়গায় আপডেট করুন।

- মূল ফোল্ডারে `server.js`
- `public/index.html`
- নতুন `public/ads/placements.js`

Render-এর Start Command `npm start`। আগের Render সার্ভিসের `TP_TOKEN` এবং `TP_MARKER` ব্যবহার করুন।

## অ্যাড পরিবর্তন

`public/ads/placements.js`-এ `top`, `left`, `right` আলাদা। প্রতিটিতে `title`, `text`, `cta`, `url` ও `img` বদলাতে পারবেন। নিজের অ্যাড ছবি `public/ads/`-এ রাখুন এবং যেমন `img: '/ads/banner.png'` দিন। কোনো স্লট লুকাতে সেই স্লটের তালিকা `[]` করুন। পাশের স্লটগুলো ১২৮০ পিক্সেল বা তার বেশি চওড়া মাউস-সমর্থিত স্ক্রিনে দেখা যাবে।

## সার্চ ও ক্যালেন্ডার

- Round trip-এ Departure ক্যালেন্ডারে প্রথম ক্লিক যাত্রা এবং দ্বিতীয় ক্লিক ফেরত। চাইলে আলাদা Return ফিল্ড থেকেও ফেরতের তারিখ সম্পাদনা করা যায়।
- নির্দিষ্ট তারিখে ০–১টি দাম পেলে সার্ভার একই মাসের ক্যাশে নির্বাচিত পূর্ণ তারিখের সঙ্গে মেলে এমন দাম খোঁজে। ফল কম থাকলে পুরো মাস খোঁজার বাটন দেওয়া হয়।
- Aviasales Data API থেকে আসা দাম সাম্প্রতিক আনুমানিক দাম। চূড়ান্ত দাম ও প্রাপ্যতা পার্টনার সাইটে যাচাই করুন।

## স্টপ ফিল্টার

রাউন্ড ট্রিপে Stops ফিল্টার যাত্রা ও ফেরতের মধ্যে যেদিকে বেশি স্টপ, সেই সংখ্যা ধরে কাজ করে। One airline per direction অপশনে প্রতিটি দিকের সব সেগমেন্ট একই অপারেটিং এয়ারলাইনের হতে হবে। ফেরতের এয়ারলাইন আলাদা হতে পারে। বর্তমান Aviasales Data API সংযোগকারী ফ্লাইটগুলোর অপারেটিং এয়ারলাইন দেয় না। তাই ওই API থেকে কেবল দুই দিকের নিশ্চিত ননস্টপ ফল এই বাটনে মেলে। কানেক্টিং ফ্লাইট যাচাই করতে ভবিষ্যৎ API অ্যাডাপ্টারে পূর্ণ `outbound_segments` ও `return_segments` অ্যারে দিতে হবে, যাতে প্রতিটি সেগমেন্টে `operating_carrier` থাকে।
