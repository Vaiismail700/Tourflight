# Tourflight Live (আসল দাম সহ)

এই প্রজেক্ট Travelpayouts-এর Data API থেকে সাম্প্রতিক সার্চ-ভিত্তিক দাম এনে আপনার সাইটে দেখায়।
টোকেন শুধু সার্ভারে থাকে, ব্রাউজারে বা কোডে নয়।

## ধাপ ০: টোকেন সুরক্ষিত করুন (আগে এটা করুন)
আপনার টোকেনের স্ক্রিনশট চ্যাটে চলে গেছে। Travelpayouts-এ Profile > API token পেজে "Regenerate token" চাপুন।
এতে পুরনো টোকেন অচল হবে। নতুন টোকেন কপি করে শুধু নিজের কাছে রাখুন।

## ধাপ ১: GitHub-এ কোড রাখুন
1. github.com-এ নতুন Repository খুলুন (নাম: tourflight-live)।
2. এই ফোল্ডারের সব ফাইল Upload করুন (public ফোল্ডারসহ)। টোকেন কোথাও লিখবেন না।

## ধাপ ২: অনলাইনে চালু করুন (উদাহরণ: render.com)
1. render.com-এ সাইন আপ করুন, New > Web Service বেছে GitHub repository যুক্ত করুন।
2. Runtime: Node। Start Command: `npm start`। Build Command ফাঁকা রাখা যায়।
3. Environment Variables অংশে নাম `TP_TOKEN`, মান আপনার নতুন টোকেন দিন।
4. Deploy চাপুন। শেষে একটি সাইট ঠিকানা পাবেন।
(হোস্টিংয়ের বর্তমান প্ল্যান, খরচ ও শর্ত নিজে দেখে নেবেন। অন্য হোস্টিংয়েও চলবে, যেখানে Node 18+ আছে।)

## ধাপ ৩: পরীক্ষা
1. ঠিকানার শেষে /health লিখে খুলুন। `"tokenSet":true` এলে টোকেন বসেছে।
2. মূল পেজে গিয়ে একটি জনপ্রিয় রুট (যেমন DAC থেকে DXB) ও ভবিষ্যতের তারিখ দিয়ে খুঁজুন।

## জেনে রাখুন
- দামগুলো মানুষের সাম্প্রতিক সার্চ থেকে আসে, তাই লাইভ নয়। কিছু রুটে কোনো দাম নাও পাওয়া যেতে পারে।
- Book Now চাপলে Aviasales সাইটে যায়। আপনার অ্যাফিলিয়েট আইডি (marker) এখনও যুক্ত নেই, তাই কমিশন হিসাব হবে না। কমিশন শুরুর সময় আমাকে বলবেন।
- প্রতিটি Book Now ক্লিক সার্ভারের লগে লেখা হয় (ট্রাফিক গোনার জন্য)।
- Travelpayouts API-র সঠিক ফরম্যাট আমি আসল সার্ভারে পরীক্ষা করিনি, শুধু নকল সার্ভার দিয়ে পরীক্ষা করেছি। প্রথম চালুর পর কিছু না দেখালে আমাকে স্ক্রিনশট পাঠান।
- দিনে ৩০টির বেশি সার্চ এক ব্যবহারকারী মিনিটে করতে পারে না (অপব্যবহার ঠেকাতে)।

## আপডেট (v2): কী বদলেছে
- কারেন্সি ঠিক করা হয়েছে (আপনার বেছে নেওয়া কারেন্সি চাওয়া হয়)।
- শহর/দেশসহ এয়ারপোর্ট তালিকা; One way, Round trip ও Multi-city।
- ফিল্টার: Direct only, 1 stop only, এয়ারলাইন, সর্টিং। ২ স্টপের ফ্লাইট আর আসে না।
- এয়ারলাইনের নাম।
- অন্য সাইটে একই ট্রিপ তুলনার লিঙ্ক (Google Flights, Skyscanner, Kayak ইত্যাদি)।
- Terms & Conditions, Privacy Policy, About পেজ ও ফুটার।
- terms.html ও privacy.html-এ [বন্ধনীর ভেতরের] অংশগুলো (নাম, দেশ, ইমেইল, তারিখ) নিজের তথ্য দিয়ে বদলে নিন, এবং একজন আইনজ্ঞকে দিয়ে দেখিয়ে নিন।
- GitHub-এ ফাইল বদলাতে: Add file > Upload files দিয়ে একই নামের ফাইল আপলোড করলে পুরনোটি বদলে যায়। নতুন html ফাইলগুলো public ফোল্ডারের ভেতরে ঢুকে আপলোড করুন।
